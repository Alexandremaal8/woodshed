# Woodshed 🎸

Guitar practice web app for iPhone: theory lessons, fretboard games, ear training, backing tracks and in-app recording.

**Open:** https://alexandremaal8.github.io/woodshed/ → Safari › Share › *Add to Home Screen*.

- `index.html`, `manifest.webmanifest`, `sw.js`, icons: the built app (served by GitHub Pages)
- `src/`: source files. Run `python3 build.py` to rebuild `index.html`.

Recordings and progress are stored on the device only.
